Информация о базе данных

Встроенная база данных H2 используется для хранения информации о книгах.

Версия: H2 2.1.214

Параметры подключения

JDBC URL
Имя пользователя
Пароль

Быстрые действия

Открыть H2 Console К списку книг Добавить книгу

Примеры SQL-запросов

SELECT * FROM books;
-- Показать все книги
SELECT COUNT(*) FROM books;
-- Количество книг
SELECT genre, COUNT(*) FROM books
GROUP BY genre;
-- Книги по жанрам
INSERT INTO books (title, author, genre, publication_year, copies)
VALUES ('Новая книга', 'Автор', 'Жанр', 2026, 5);

Статистика базы данных

Параметр Значение Описание
Таблицы 1 Основная таблица "books"
Тип БД In-Memory Данные хранятся в оперативной памяти
Режим работы Разработка Используется для тестирования и разработки
Доступ Только локальный Консоль доступна только с localhost
Важная информация
  • База данных H2 - in-memory (в оперативной памяти)
  • Данные исчезают при перезапуске приложения
  • Для продакшена используйте PostgreSQL, MySQL или другую постоянную БД
  • H2 Console предназначена только для разработки
