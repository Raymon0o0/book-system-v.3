 🎯 Описание проекта

Библиотечная система управления книжным фондом - это веб-приложение для автоматизации учета книг в библиотеке. Система позволяет вести каталог книг, осуществлять поиск, добавлять/редактировать/удалять записи, просматривать статистику и получать рекомендации похожих книг.

 Цель работы
Разработка полнофункциональной веб-системы для управления книжным фондом библиотеки с использованием современных Java-технологий.

 Задачи
1. ✅ Спроектировать структуру базы данных для хранения информации о книгах
2. ✅ Реализовать CRUD-операции для работы с книгами
3. ✅ Разработать интуитивно понятный пользовательский интерфейс
4. ✅ Реализовать систему поиска и фильтрации книг
5. ✅ Добавить функцию рекомендации похожих книг
6. ✅ Внедрить статистику и аналитику
7. ✅ Обеспечить валидацию данных

 🚀 Установка и запуск

 Предварительные требования
- Java Development Kit (JDK) 17 или выше
- Maven 3.6+ для сборки проекта
- Интернет-браузер для работы с веб-интерфейсом

 Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/ваш-логин/library-book-system.git
cd library-book-system
```

 Шаг 2: Сборка проекта
```bash
mvn clean package
```

 Шаг 3: Запуск приложения
```bash
 Способ 1: Через Maven
mvn spring-boot:run

 Способ 2: Запуск собранного JAR
java -jar target/book-system-0.0.1-SNAPSHOT.jar
```

 Шаг 4: Открытие в браузере
После запуска откройте браузер и перейдите по адресу:
```
http://localhost:8080
```

 📖 Использование

 Основные страницы
1. Главная страница (`/`) - Каталог всех книг с поиском и фильтрацией
2. Добавление книги (`/add`) - Форма для добавления новой книги
3. Детали книги (`/book/{id}`) - Полная информация о книге и рекомендации
4. Статистика (`/stats`) - Статистические данные о книжном фонде
5. Управление БД (`/database`) - Информация о базе данных

 Работа с данными
- Для добавления книги нажмите "Добавить книгу" в навигации
- Для редактирования книги нажмите иконку карандаша в таблице
- Для удаления книги нажмите иконку корзины (требуется подтверждение)
- Для поиска используйте форму фильтрации вверху таблицы

 База данных H2
Встроенная база данных доступна по адресу:
```
http://localhost:8080/h2-console
```

Параметры подключения:
- JDBC URL: `jdbc:h2:mem:librarydb`
- User Name: `librarian`
- Password: `secret123`

 🔌 API Endpoints

 Основные маршруты
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Главная страница с каталогом книг |
| GET | `/add` | Форма добавления новой книги |
| POST | `/save` | Сохранение новой книги |
| GET | `/edit/{id}` | Форма редактирования книги |
| POST | `/update/{id}` | Обновление информации о книге |
| GET | `/delete/{id}` | Удаление книги |
| GET | `/book/{id}` | Детальная информация о книге |
| GET | `/stats` | Статистика книжного фонда |
| GET | `/database` | Информация о базе данных |
| GET | `/search` | Поиск книг с фильтрами |

 Примеры HTTP-запросов
```http
GET /search?title=Война&author=Толстой&genre=Роман&year=1869
GET /book/1
POST /save (с данными книги в теле запроса)
```

 💻 Разработка

 Модель данных (Book.java)
Сущность книги включает следующие поля:
- `id` - уникальный идентификатор
- `title` - название книги
- `author` - автор
- `genre` - жанр
- `publicationYear` - год издания
- `copies` - количество экземпляров
- `description` - описание книги
- `authorBio` - биография автора
- `publisher` - издательство
- `isbn` - ISBN код
- `pages` - количество страниц

 Алгоритм рекомендаций
Система использует алгоритм с весами для поиска похожих книг:
1. Книги того же жанра - 3 балла
2. Книги того же автора - 2 балла
3. Книги с похожим названием - 1 балл
4. Случайные книги - если недостаточно рекомендаций
